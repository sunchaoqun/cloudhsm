① 签名 / 验签

输入明文 → 点“签名”生成签名 → 点“验签”校验。改一下明文再验签会失败（演示防篡改）。

② 加密 / 解密

输入明文 → 点“加密”得到密文 → 点“解密”还原，验证与原文一致。

③ 非对称加解密 (RSA)

公钥加密 → 私钥解密（RSA-OAEP）。注意 RSA 只能加密短数据（RSA-2048 约 ≤190 字节），太长会报错。

切换后端：以不同 profile 启动应用（kms / kms-cks / jce / pkcs11）。接口 /api/* 保持一致；按钮按后端能力自动显示。
